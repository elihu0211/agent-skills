# 規格寫法

一張圖一份 YAML。引擎只認下列鍵，拼錯或多寫都會以 `schema` 規則擋下並指出位置。完整範例見 [`../assets/examples/`](../assets/examples/)。

## 頂層

| 鍵 | 必填 | 內容 |
| --- | --- | --- |
| `title` | 是 | 圖的標題，一句名詞片語 |
| `subtitle` | 否 | 括號副標：範圍與讀法，例如「（A 與 B 對照 — 依什麼原則歸層）」 |
| `footer` | 否 | 整張圖的一句結論；引擎自動在前面加「★ 」 |
| `label` | 否 | 有 `columns` 時，左上角層名欄的欄標題（預設「分層」） |
| `columns` | 否 | 1–3 欄的對照欄；不寫就是單欄圖 |
| `bands` | 是 | 由上而下的各層 |
| `width` | 否 | 畫布寬，1200–4000 像素（預設 2000）；PNG 再乘 `--scale` |

## `columns`

每欄 `{title, note?, color?}`：`title` 粗體黑字，`note` 接在後面、用 `color` 的字色（預設 `blue`）。欄色用來區分「誰」，例如兩套系統各一色。

## `bands`

| 鍵 | 必填 | 內容 |
| --- | --- | --- |
| `color` | 是 | 層色，見〈色票〉 |
| `name` | 是 | 層名，左側面板第一行（粗體、層色） |
| `en` | 否 | 第二行，常放英文或括號別名 |
| `note` | 否 | 第三行灰字：這一層的設備、角色或附註 |
| `dashed` | 否 | `true` 時層帶與方塊都畫虛線：標準之外、延伸或願景的層 |
| `cells` | 有 `columns` 時 | 每欄一格，格數要等於欄數；每格是方塊清單 |
| `boxes` | 沒有 `columns` 時 | 這一層的方塊清單 |
| `bridge` | 否 | 這一層與下一層之間的說明框：字串，或 `{text, arrow}`，`arrow` 為 `none`（預設）、`down`、`up`、`both`；最後一層不能放 |

## 方塊

每個方塊是 1–3 行字串 `[標題, 重點, 補充]`，一格 1–4 個方塊、平分寬度：

- **標題**：深色粗體，名詞（協定、元件、系統名）。
- **重點**：層色粗體，這個方塊最該被記住的一點。
- **補充**：灰字，限定條件、例子或來源上的提醒（如「審查中草案」）。

行數少於三行時整組垂直置中。

## 字數參考

文字超出方塊就以 `overflow` 擋下。預設畫布寬 2000 時，各位置大約放得下的全形字數（英數約可多放一半）：

| 版面 | 標題 | 重點 | 補充 |
| --- | --- | --- | --- |
| 單欄，每層 3 方塊 | 22 | 28 | 31 |
| 兩欄，每格 1 方塊 | 34 | 42 | 47 |
| 兩欄，每格 2 方塊 | 16 | 20 | 22 |
| 兩欄，每格 3 方塊 | 10 | 12 | 14 |
| 三欄，每格 2 方塊 | 10 | 12 | 14 |

左側面板：層名約 9 字、第二行約 14 字、附註約 16 字。說明框只寫一句，盡量短於 30 字。

## 色票

| 名稱 | 常見用途 |
| --- | --- |
| `blue` | 最上層的應用、業務或規劃 |
| `purple` | 語意、知識、推理、資料表示 |
| `teal` | 會話、整合、協作 |
| `yellow` | 傳輸、匯流排、事件流 |
| `orange` | 網路、路由、閘道 |
| `green` | 執行、現場、資料鏈結、代理 |
| `gray` | 最底層的實體、設備、基礎設施 |
| `rose` | 標準之外、延伸、願景（常配 `dashed: true`） |

同一張圖相鄰兩層用不同顏色；同一個意思在系列圖裡用同一個顏色。說明框沿用它上方那一層的顏色。

## 結束碼與 JSON

`0` 成功；`1` 規格有誤或文字溢出（每條一行 `✗ [規則] 位置：說明`，規則為 `schema` 或 `overflow`）；`2` 執行環境問題（讀不到檔、找不到 Chrome、截圖失敗）。加 `--json` 時輸出 `{ok, issues[{rule, where, message}], size, output}`，`--check` 的 `size` 是畫布尺寸，輸出 PNG 時是 PNG 尺寸。找 Chrome 的順序：環境變數 `CHROME`、macOS 的 Google Chrome、`PATH` 上的 `google-chrome`／`chromium`。
