# 規格寫法

一張圖一份 YAML。引擎只認下列鍵，拼錯或多寫都會以 `schema` 規則擋下並指出位置。完整範例見 [`../assets/examples/`](../assets/examples/)。

引擎有兩種模式，依規格內容自動判定：

| 模式 | 何時用 | 判定 |
| --- | --- | --- |
| 層帶模式 | 讀者要看的是「誰在哪一層」：每層一列等寬方塊，層與層之間一個說明框 | 沒有 `rows` 也沒有 `edges` |
| 節點圖模式 | 讀者要看的是「誰跟誰相連」：同層或跨層的節點之間有連線、一層有多列、有回饋線或群組 | 任一層有 `rows`，或頂層有 `edges` |

先寫層帶模式的鍵（下列〈頂層〉到〈字數參考〉），節點圖模式見〈節點圖模式〉；色票與結束碼兩種模式共用。

## 頂層

| 鍵 | 必填 | 內容 |
| --- | --- | --- |
| `title` | 是 | 圖的標題，一句名詞片語 |
| `subtitle` | 否 | 括號副標：範圍與讀法，例如「（A 與 B 對照 — 依什麼原則歸層）」 |
| `footer` | 否 | 整張圖的一句結論；引擎自動在前面加「★ 」 |
| `label` | 否 | 有 `columns` 時，左上角層名欄的欄標題（預設「分層」） |
| `columns` | 否 | 1–3 欄的對照欄；不寫就是單欄圖 |
| `bands` | 是 | 由上而下的各層 |
| `width` | 否 | 畫布寬，1200–4000 像素（預設 2000）；PNG 再乘 `--scale` |

## `columns`

每欄 `{title, note?, color?}`：`title` 粗體黑字，`note` 接在後面、用 `color` 的字色（預設 `blue`）。欄色用來區分「誰」，例如兩套系統各一色。

## `bands`

| 鍵 | 必填 | 內容 |
| --- | --- | --- |
| `color` | 是 | 層色，見〈色票〉 |
| `name` | 是 | 層名，左側面板第一行（粗體、層色） |
| `en` | 否 | 第二行，常放英文或括號別名 |
| `note` | 否 | 第三行灰字：這一層的設備、角色或附註 |
| `dashed` | 否 | `true` 時層帶與方塊都畫虛線：標準之外、延伸或願景的層 |
| `cells` | 有 `columns` 時 | 每欄一格，格數要等於欄數；每格是方塊清單 |
| `boxes` | 沒有 `columns` 時 | 這一層的方塊清單 |
| `bridge` | 否 | 這一層與下一層之間的說明框：字串，或 `{text, arrow}`，`arrow` 為 `none`（預設）、`down`、`up`、`both`；最後一層不能放 |

## 方塊

每個方塊是 1–3 行字串 `[標題, 重點, 補充]`，一格 1–4 個方塊、平分寬度：

- **標題**：深色粗體，名詞（協定、元件、系統名）。
- **重點**：層色粗體，這個方塊最該被記住的一點。
- **補充**：灰字，限定條件、例子或來源上的提醒（如「審查中草案」）。

行數少於三行時整組垂直置中。

## 字數參考

文字超出方塊就以 `overflow` 擋下。預設畫布寬 2000 時，各位置大約放得下的全形字數（英數約可多放一半）：

| 版面 | 標題 | 重點 | 補充 |
| --- | --- | --- | --- |
| 單欄，每層 3 方塊 | 22 | 28 | 31 |
| 兩欄，每格 1 方塊 | 34 | 42 | 47 |
| 兩欄，每格 2 方塊 | 16 | 20 | 22 |
| 兩欄，每格 3 方塊 | 10 | 12 | 14 |
| 三欄，每格 2 方塊 | 10 | 12 | 14 |

左側面板：層名約 9 字、第二行約 14 字、附註約 16 字。說明框只寫一句，盡量短於 30 字。

## 節點圖模式

節點照格線擺放、連線照規格走，引擎不自動排版：位置和走線是作者的決定，引擎負責畫成一致的風格，並擋下不乾淨的版面。

### 頂層

`title`、`subtitle`、`footer` 同層帶模式（`footer` 可省略）；另有：

| 鍵 | 必填 | 內容 |
| --- | --- | --- |
| `width` | 否 | 畫布寬，1200–4000（預設 2200） |
| `grid` | 否 | 層帶內容區分成幾欄（預設 48）；所有層共用同一組欄位，上下對齊靠它 |
| `labels` | 否 | `side`（預設，左側層名面板）或 `top`（層名寫在層框內上方，內容用滿整層寬度） |
| `rails` | 否 | 跨多層的左右側欄 |
| `bands` | 是 | 由上而下的各層，每層用 `rows` |
| `edges` | 否 | 連線清單 |

### `bands`

| 鍵 | 必填 | 內容 |
| --- | --- | --- |
| `color`、`note`、`dashed` | — | 同層帶模式 |
| `en` | 否 | 英文名或別名，字串或 2 行清單 |
| `name` | 是 | 層名，字串或 2 行清單；`labels: top` 時可省略，該層只畫淡色底框 |
| `id` | 否 | 給了就能讓連線接到整個層框（如側欄對整套系統），層框本身不擋線 |
| `title_align` | 否 | `labels: top` 時層名靠 `left`（預設）或 `center`；層名占的空間由作者用 `pad` 讓出，或讓第一列節點避開它 |
| `rows` | 是 | 由上而下的各列；每列是節點清單，同列節點同高 |
| `groups` | 否 | 把同層幾個節點圈成一組：`{id, title, wraps: [節點 id], color?, dashed?}`；外框比成員上方多 48、其他三邊多 28 像素（容得下接到成員的箭頭），用 `pad` 讓出空間 |
| `pad` | 否 | `[上留白, 下留白]`（預設 `[24, 24]`）；ㄩ字回路要走在層帶裡時加大 |
| `row_gap` | 否 | 列與列的間距（預設 52） |
| `gap` | 否 | 和下一層的間距（預設 52）；跨層的橫向走線與標籤放在這裡 |

### 節點

| 鍵 | 必填 | 內容 |
| --- | --- | --- |
| `id` | 是 | 全圖唯一，不含空白、`.`、`@` |
| `at` | 是 | `[起始欄, 欄寬]`，欄從 1 起，可用小數微調 |
| `text` | 是 | 1–6 行；第一行是標題（深色粗體），其餘是灰色說明 |
| `title_lines` | 否 | 標題占幾行（預設 1），長名稱分兩行時用 |
| `bullets` | 否 | 寫了就是條列面板：`text` 只放一行膠囊標題，這裡放 1–6 個 `[重點, 說明?, 說明色票?]`；`align` 用 `left`（預設）或 `right` |
| `block` | 否 | `down` 或 `up`：大型方向箭頭，表達一整段資料流；不寫 `text`，高度跟著同列節點 |
| `accent` | 否 | 哪幾行改用節點色加粗：`true`（最後一行）、行號或行號清單 |
| `strong` | 否 | `true` 用深色粗框，標出這張圖的主角 |
| `callout` | 否 | `true` 畫成淡底旁註：各行同字級，`accent` 的行用節點色 |
| `color`、`dashed` | 否 | 預設跟著所在的層 |
| `accent_color` | 否 | `accent` 行的顏色（預設同節點色），如白底旁註裡的紅字 |
| `divider` | 否 | 行號：在這一行下面畫分隔線 |
| `fill` | 否 | `white` 或 `tint`（節點色的淡底）；節點預設白底，旁註預設淡底 |
| `align` | 否 | `center`（預設）或 `left`，多行旁註常用靠左 |

### `rails`

跨多層的側欄，寫在頂層：`{id, side, bands: [起始層, 結束層], text, title_lines?, color?}`。`side` 是 `left` 或 `right`，`text` 1–8 行畫在中央白卡上。層帶會自動讓出側欄的寬度；連線可以用側欄的 `id` 接在它的邊上（用 `@` 對準要接的高度）。

### `edges`

| 鍵 | 必填 | 內容 |
| --- | --- | --- |
| `from`、`to` | 是 | `節點`、`節點.邊` 或 `節點.邊@位置`；邊是 `top`／`bottom`／`left`／`right`，位置 0–1（由左或由上算）。節點也可以是群組 id |
| `label` | 否 | 字串或 1–3 行清單 |
| `label_at` | 否 | 標籤放在整條線的哪個比例位置（0 是起點）；省略時放在最長那段的中點 |
| `shift` | 否 | `[橫移, 縱移]` 像素，微調標籤 |
| `style` | 否 | `solid`（預設）或 `dashed`（回饋、檢索這類非主要流向） |
| `weight` | 否 | `normal`（預設）或 `thick`（主要流向） |
| `arrow` | 否 | `end`（預設）、`both`、`none` |
| `color`、`label_color` | 否 | 色票名稱；`label_color` 省略時跟著 `color` |
| `channel` | 否 | 三段折線的中間段位置，0–1（0 靠起點，預設 0.5） |
| `depth` | 否 | ㄩ字回路往外凸出的像素（預設 46） |

`from`、`to` 也可以是層的 `id` 或側欄的 `id`。

走線規則：不寫邊時，左右分開且高度重疊就走左右兩邊，否則走上下兩邊。

| 兩端的邊 | 畫法 |
| --- | --- |
| 相對（下接上、右接左） | 能拉直就拉直：沒寫 `@` 的一端移到對面正前方；否則走三段折線，用 `channel` 調中段 |
| 同一邊（下接下、上接上） | ㄩ字回路，用 `depth` 調深度 |
| 一橫一直（上接右） | 轉一次彎 |

兩條線交叉時，橫線畫跳線弧；從同一點出發或進到同一點的線視為分岔與匯流，可以共用線段，實線畫在虛線上面。

### 版面守門（`layout`）

下列任一情形都以 `layout` 擋下，不出圖：

- 節點彼此重疊，或間距不到 8 像素。
- 連線穿過或貼到節點、進到左側層名面板，或跑出層帶區域。
- 兩條不相干的線有一段疊在一起。
- 箭頭前的線段太短。
- 標籤壓到節點、別的標籤或不相干的線，或超出範圍。
- 標籤壓到層框邊線：整個放在層內或層間空隙，離邊線至少 4 像素。位移不大就能移開時，訊息直接給建議的 `shift`（只考慮層框，改完仍照其他守門檢查）。
- 標籤蓋住箭頭（含自己這條線的）：移開標籤，或拉開兩端節點讓箭頭露出來。

修法依序是：換接點邊或位置（`@`）、調 `channel`／`depth`、加大 `gap`／`pad`、移動節點的 `at`、把標籤拆成多行。守門放不過去通常代表讀者也看不清楚。

## 色票

| 名稱 | 常見用途 |
| --- | --- |
| `blue` | 最上層的應用、業務或規劃 |
| `purple` | 語意、知識、推理、資料表示 |
| `teal` | 會話、整合、協作 |
| `yellow` | 傳輸、匯流排、事件流 |
| `orange` | 網路、路由、閘道 |
| `green` | 執行、現場、資料鏈結、代理 |
| `gray` | 最底層的實體、設備、基礎設施 |
| `rose` | 標準之外、延伸、願景（常配 `dashed: true`） |

同一張圖相鄰兩層用不同顏色；同一個意思在系列圖裡用同一個顏色。說明框沿用它上方那一層的顏色。

## 結束碼與 JSON

`0` 成功；`1` 規格有誤、文字溢出或版面不乾淨（每條一行 `✗ [規則] 位置：說明`，規則為 `schema`、`overflow` 或 `layout`）；`2` 執行環境問題（讀不到檔、找不到 Chrome、截圖失敗）。加 `--json` 時輸出 `{ok, issues[{rule, where, message}], size, output}`，`--check` 的 `size` 是畫布尺寸，輸出 PNG 時是 PNG 尺寸。找 Chrome 的順序：環境變數 `CHROME`、macOS 的 Google Chrome、`PATH` 上的 `google-chrome`／`chromium`。
