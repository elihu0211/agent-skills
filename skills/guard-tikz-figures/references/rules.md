## 量法

每張 `tikzpicture` 單獨放在一頁大紙上編譯（150cm 見方），圖尾加一個記號框標出圖的外框與序號；PyMuPDF 讀出框內所有路徑（`get_drawings`）與每個字的外框（`rawdict`），座標單位是 PDF 點（約等於 TeX 的 pt）。圖形依畫法分類：

| 類別 | 判斷 | 例子 |
|------|------|------|
| 節點 | 有框線的封閉路徑（填色可有可無） | `box`、`decision`、`terminal`、`annot` |
| 外框（容器） | 完全包住其他節點的節點，或只填色、包住節點的背景 | `fit` 區域、群組框、泳道 |
| 邊標籤 | 只填色、沒框線、裡面有字的封閉路徑 | `edge-label`、`msg-label` 這類白底標籤 |
| 裸字標籤 | 不在任何節點或標籤框裡的一行字 | `node[above]{…}` 沒有白底的字、`label=` |
| 連線 | 只描邊的開放路徑；`double`、`preaction` 畫兩次的同一條線算一條 | `\draw[->]`、`leader` 虛線 |
| 箭頭 | 14pt 以內、字沒有大半落在裡面的封閉小圖形，以及接在線端的 8pt 以內小筆畫（`->` 的 to 箭頭） | Stealth、Latex、to |
| 導引線 | 沒有箭頭、最多一端接到節點的虛線 | 序列圖的生命線、時間軸 |

線端（含接在那裡的箭頭）離節點外形 4pt 以內，就算接到那個節點。字的外框只算有墨跡的部分：行首、行尾的全形標點只算半個字寬（xeCJK 的標點擠壓會讓空的那半邊伸出節點）。

## 規則

### node-overlap

- **量什麼**：非外框節點兩兩之間，重疊面積超過 1pt²，或框線外緣的間距小於 `--min-gap`（預設 2pt）；外框與不屬於它的節點重疊超過 1pt²（外框邊線切過節點）；兩個外框部分交疊（不是一個包住另一個）。
- **不報**：外框和它包住的成員。
- **修法**：加大 `node distance` 或該節點的定位距離（`below=12mm of a`）；外框切過節點時，把節點加進 `fit=(…)` 清單，或改放到外框外；兩組外框交疊就拉開兩組節點。

### edge-through-node

- **量什麼**：連線經過兩端以外的節點，且碰到節點內縮 2pt 後的範圍（起訖點接在邊界上不算穿過）。
- **不報**：線的兩端節點；外框（線本來就要穿過外框邊線接到成員）；導引線（生命線被 `note`、activation 蓋住是序列圖的慣例）。
- **修法**：直線換成經轉折點的折線，從節點外側繞過：

  ```latex
  % 穿過中間的 b
  \draw[->] (a) -- (c);
  % 改從上方繞
  \draw[->] (a.north) -- ++(0,4mm) -| (c.north);
  ```

  曲線（`to[out=…,in=…]`、`bend`）改出入角度，或改成折線。`leader` 虛線也一樣不能穿過節點。

### label-on-node

- **量什麼**：邊標籤的白底框（裸字取字的外框）內縮 0.5pt 後，與節點重疊面積超過 2pt²。白底框會蓋掉節點的框線，所以框比字大的部分也算。
- **修法**：
  - 標籤比兩節點間的空隙寬：拉開節點，或把標籤放到線的一側（`above`、`right`）。
  - 標籤在線端附近：`pos` 移到 0.4～0.6。
  - 標籤寫的是目標節點的身分（角色名、分支名）：改成節點的粗體標題，連線不帶字。

    ```latex
    \node[box, text width=3.6cm] (sup) {\textbf{supervisor}\\uploader 全部 +\\行為分析};
    \draw[->] (check.south) |- ++(0,-0.55) -| (sup.north);
    ```

### label-on-label

- **量什麼**：兩個標籤框重疊面積超過 0.5pt²。
- **修法**：錯開 `pos`，或把其中一個放到線的另一側；兩條線的標籤擠在一起時，錯開兩條線的接點。

### label-on-arrow

- **量什麼**：標籤框蓋住箭頭面積的四分之一以上（且超過 1pt²）。
- **不報**：標籤貼著自己的線、只擦過箭頭翼尖（實測多半蓋住 13%～17%）。
- **修法**：`pos` 不要超過 0.8；線段太短放不下標籤與箭頭時，加大節點間距。`-|`／`|-` 折線的 `pos=0.5` 是轉角，`0.75` 是第二段中點：

  ```latex
  % pos=0.9 正好蓋住箭頭
  \draw[->] (a.south) -| node[edge-label, pos=0.9] {staff} (b.north);
  % 放在垂直段中點、線的右側
  \draw[->] (a.south) -| node[edge-label, pos=0.75, right] {staff} (b.north);
  ```

### text-overflow

- **量什麼**：節點裡每一行字的墨跡外框，超出節點外形（扣掉半個框線寬，容許 0.5pt）。圓角矩形、膠囊這類面積達外框九成的形狀以外框判斷；菱形、橢圓以多邊形判斷，所以字的角落伸出菱形斜邊也會擋。
- **修法**：縮短字句；長句加 `text width` 並以 `\\` 換行（`text width` 小於最長的字詞時，TeX 會讓字溢出框外）；菱形加大 `aspect`（2.4 以上）或 `inner sep`（2pt 以上），不要用負的 `inner sep`。

### edge-overlap

- **量什麼**：兩條不同的連線有直線段共線（夾角 1° 內、相距 0.8pt 內），重疊超過 6pt。
- **不報**：兩條線有共同端點（從同一錨點分岔、匯入同一錨點），共用的線段是刻意的匯流排。
- **修法**：錯開接點（`.north east`、`([xshift=2mm]b.north)`）或轉折位置，讓兩條線各走各的通道。

### figure-width

- **量什麼**：只在給了 `--max-width` 時檢查，圖的原尺寸寬度（不含 `\resizebox` 縮放）超過上限。上限通常給版心寬（例如 A4 左右各 2.5cm 時約 16cm）。
- **修法**：縮小 `node distance`、文字換行，或把橫向流程改成直向。

### compile

- **量什麼**：這張圖單獨編譯失敗；其他圖照常量測。
- **修法**：修訊息指出的 LaTeX 錯誤。文件本身編得過、單獨編卻失敗，表示圖依賴正文裡定義的巨集或顏色，把它們移進前置檔。

## 放行註記

刻意的疊放（角標貼在卡片角上、序號圓圈壓在方框上）在 `\begin{tikzpicture}` 正上方的註解行或圖裡寫：

```latex
% tikz-guard: allow node-overlap  % 序號角標刻意壓在卡片右上角
\begin{tikzpicture}
```

多條規則以逗號分隔。只放行該圖的列出規則；其他規則照常檢查。

## 量不到的情況

- `\tikz …;` 短式與寫在巨集定義裡（含 `#1` 參數）的圖不會被抽出來。
- `overlay`、`remember picture` 的圖沒有外框，略過並警告。
- 字型缺字（前置沒有載入能顯示該字的字型）時會警告：缺的字印不出來，字寬也量不準。
- 圖裡 `\input` 或引用的外部檔案改了，快取不會失效；需要時加 `--no-cache`。
- `\clip` 裁掉的部分仍會被量到；`shade` 的漸層不是路徑，不算節點。
