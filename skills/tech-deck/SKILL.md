# 技術簡報排版風格（Tech Deck）

本技能封裝現代高階工程發表會（Keynote / NVIDIA 風格）的投影片架構與排版標準。以白底、直角細線、單一語義強調色與嚴謹工程結構為基礎，將投影片視為「資訊密度的極簡載體」，透過純 Python（`python-pptx`）宣告式規格自動化生成，兼具極致美感與可重現性。

## 先讀

- 消費端 repo 的 `AGENTS.md`：若專案已有定義簡報腳本目錄或特定色票，以該 repo 為準。
- 完整程式碼範本與原語實作見 [references/patterns.md](references/patterns.md)。

## 設計核心原則

1. **白底極簡（White Canvas）：** 全頁純白底色（`#FFFFFF`），徹底摒棄漸層色底、浮雕裝飾、陰影特效與玩具般的圓角矩形。所有外框皆為直角細線（`0.75pt`–`1.5pt`）。
2. **語義色票系統（Semantic Colors）：**
   - **墨黑（`#111111`）：** 標題、主要內文、表頭底色。
   - **強調綠（`#76B900` / `#5A8F00`）：** 唯一正面強調色，用於綠框、確定執行、通過驗證。
   - **警戒紅（`#B91C1C`）：** 防錯攔截（Poka-Yoke）、問題痛點、違規警戒。
   - **中性灰（`#555555` / 淺灰 `#F3F3F3` / `#F6F6F6`）：** 次要說明、唯讀主檔、交錯斑馬紋。
   - **虛線框（`#8A8A8A` Dash）：** 中間判斷、待驗輸入。
3. **零折行與抗孤字原則（Zero-Wrap Rule）：**
   - 標題單行不換行，卡片與表格每行皆不自動折行。
   - 嚴格控制每行字元長度（如 3 欄卡片每行 $\le$ 14 字元），杜絕中文字詞被腰斬或末尾 3–4 字落單換行（寡字孤行）。
   - 內容採「**四字粗體標籤**＋精煉說明」或「現象/後果」二層結構，剔除口語贅字，確保工業工程（IE）信息聚焦。
4. **講稿備註分流（Slide Notes）：** 投影片本體只保留高密度骨架、數據與圖形；鋪陳描述、背景說明與口頭引導一律移入 Slide Notes。

## 版心網格與尺寸標準（16:9 寬螢幕）

- 投影片比例：`16:9`，寬度 `13.333` 英吋，高度 `7.50` 英吋。
- 版心邊界：
  - 左邊界 `T.LM = 0.80 in`，右邊界 `T.RM = 12.53 in`，可用內容寬度 `T.W = 11.73 in`。
  - 上方起始 `T.TOP = 1.70 in`（預留主標題與分類標籤），下方安全底線 `T.BOTTOM = 6.60 in`（保留足夠邊界遠離頁尾線 `7.00 in`）。
- 字型系統：繁體中文一律使用 `PingFang TC`（Mac）或 `Microsoft JhengHei`（Win）。

## 八大佈局原語（Layout Primitives）

| 原語名稱 | 呼叫方式 | 典型用途與排版特徵 |
| :--- | :--- | :--- |
| **Cards** | `cards(slide, y, items)` | 水平語義卡片列（3 或 4 欄），垂直置中，可選箭頭導引或直角邊框。 |
| **Table** | `table(slide, y, rows)` | 現代專業表格：首列黑底白字，奇偶行白/淺灰交錯，綠/紅條件高亮儲存格。 |
| **Flow** | `flow(slide, y0, y1)` | 三泳道業務流程圖：泳道分層，透明背景文字標籤，直角連線。 |
| **Gallery** | `gallery(slide, y, items)` | 左側實際二維碼或架構圖片，右側縱向堆疊語義說明卡片。 |
| **Columns** | `columns(slide, y, cols)` | 推進計畫或結論總結：頂部細線、大號綠/黑標題、短條列。 |
| **Steps** | `steps(slide, y, items)` | 序號步驟列：頂部綠線、大號序號綠字（34pt）、下方精煉說明。 |
| **Banner** | `banner(slide, y, kind)` | 全寬核心問題或關鍵主張框，橫貫頁面強化焦點。 |
| **Note** | `note(slide, y, lines)` | 頁面底部帶細分隔線的總結列，支援 `**粗體**` 強調。 |

## 程式碼三層架構

技術簡報應採「規格與渲染分離」架構進行維護：

1. **`theme.py`（樣式主題）：** 純定義 RGB 色票、字型常數、版心尺寸與卡片樣式字典，不寫入任何排版邏輯。
2. **`deck_engine.py`（佈局引擎）：** 封裝八大版面佈局原語，負責呼叫 `python-pptx` 繪製圖形、文字框、表格與連線。
3. **`deck_spec.py`（宣告式規格）：** 純 Python 資料字典，集中宣告每頁標題、佈局區塊、內文項目與講稿備註。
4. **`build_deck.py`（建置腳本）：** 一鍵執行建置、渲染產出 PPTX，並可透過 AppleScript 或工具鏈自動轉為 PDF 進行視覺驗證。

## 零折行檢查清單

產出或優化簡報時，必須逐頁檢核以下項目：

- [ ] 主標題是否為單行（不超過 24 個中文字）？
- [ ] 3 欄卡片內文每行是否控制在 **14 字元以內**？
- [ ] 卡片是否有任何文字在第二行只留下 3–4 個孤字？若有，必須改寫為精煉用詞或結構化標籤。
- [ ] 流程圖中連線標籤的文字框背景是否設定為**完全透明**（無白底方塊覆蓋泳道）？
- [ ] 內容是否剔除口語化敘述（如「雙手沾油」），聚焦於「作業現象、數據失真、管理後果」？
- [ ] 表格是否有設定明確的欄寬比例（`col_w`）與儲存格邊距？
- [ ] 底部 Note 是否控制在單行且緊靠安全底線（遠離頁尾線）？

## 規則

- **白底黑字無圓角。** 嚴格使用白底（`#FFFFFF`）與直角形狀；不使用彩色漸層、大面積色塊或圓角形狀。
- **嚴格零折行。** 卡片每點文字寧可少寫兩字，也不容許單一詞彙被腰斬換行。
- **透明連線標籤。** 流程圖連線上的標籤文字框一律透明，不得添加不透明實心白色矩形底。
- **規範單一真值源。** 投影片內容一律於 `deck_spec.py` 定義，不手動在 PPT 軟體中隨意拖曳排版。
