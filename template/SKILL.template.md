# 技能名稱

一段話：這個技能產出什麼結果、封裝了哪些判斷。

## 先讀

- 消費端 repo 的 `AGENTS.md`：它的指令、結構與慣例優先於本技能。
- 條件成立時讀 [references/REFERENCE.md](references/REFERENCE.md)。技能不需要參考檔時，刪掉這一行。

## 步驟

1. ... 完成：可檢查的一句話（例如「每個修改過的檔案都列在清單裡」）。
2. ... 完成：...

## 規則

- 規則寫成要做的事，每條附理由；只有擋不住就會出事的才用禁止句，並同時寫出該做什麼。
